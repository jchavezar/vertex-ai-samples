Customer AuthN & AuthZ Setup

1. Authorized Redirect URIs for your GCP Console:

http://localhost:8003/api/auth/callback
http://localhost:8003

Add both URLs under Authorized redirect URIs in your GCP OAuth 2.0 Web Client credentials.

Mandatory Google Cloud IAM Requirement:

Every user or service account must have the roles/mcp.toolUser role in the active GCP project.

gcloud projects add-iam-policy-binding PROJECT_ID --member="user:EMAIL" --role="roles/mcp.toolUser" --condition=None

Google Workspace Scopes Granted during AuthZ:

  • openid, userinfo.email, userinfo.profile (AuthN Identity)
  • gmail.modify (Gmail Tools)
  • drive.readonly (Google Drive Tools)
  • calendar (Google Calendar Tools)
  • documents.readonly (Google Docs Tools)
  • spreadsheets.readonly (Google Sheets Tools)
