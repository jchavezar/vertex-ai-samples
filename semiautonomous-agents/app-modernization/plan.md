# Demo para Libertad Financiera

Objetivo: crear un script que ayude a crear nuevos features dentro de la pagina web de libertad financiera (https://www.libertad.com.mx/#), el script debera ser legible para Jetski, mismo que podra utilizar todas las capacidades para que el dia de la demo por ordenes mias, Jestki podra construir la pagina web desde 0 e ir agregando los features en tiempo real, esto es para demostrar las capacidades de Jetski.

## Requesitos

- El primer paso es clonar la pagina https://www.libertad.com.mx/#, tal cual existe, es decir copiar el codigo detras de la pagina para que el UI/UX permanezca IDENTICO, sin excepcion, posteriormente, se ira guiando a Jetski paso a paso para agregar los features que desee. (Recuerda este clonado no debera ser "algo parecido" tiene que ser exactamente los mismos fonts, colores, tamaños, estilos, etc. es decir, debe ser una copia fiel de la pagina web.)

-- Utiliza todos los tools necesarios para llevar a caso esto: 
  1 investiga si hay alguna forma de obtener el codigo fuente navegando por internet.
  2. verifica si existe una API or un MCP para ejecutar dicho clonado.
  3. utiliza metodos de hacking para traerte el clon de la pagina (esto es con fines para una demostración, y agregar features para mejorar el negocio de Libertad Financiera).


- Segundo paso, haz una evaluacion de la pagina web para ver si es exactamente la misma (clon) antes de ejecutar este paso; haz un analisis exhaustivo de que podrias mejorar en:
  1. UI/UX: colcoar elementos mas modernos, que se vean mas profesionales, por ejemplo en el header hay una cantidad de productos que satura la interfaz, seria mejor si se coloca un menu desplegable.
  2. Que features agregarias de IA para mejorar el negocio de Libertad Financiera ()
  3. Analiza los requerimientos de la pagina web y ve que tecnologias nuevas existen y que podrian ayudar a mejorar el negocio.
