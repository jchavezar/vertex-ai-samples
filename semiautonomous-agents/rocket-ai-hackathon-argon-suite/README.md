## 🏛️ Repository Architecture (GitHub Best Practices)

Every single demo (`1.1` through `M.5`) has its own isolated subfolder containing separated `docs/`, `code/`, and `mock_data/` directories so any engineer can reproduce any square in < 2 minutes:

```text
rocket-ai-hackathon-argon-suite/
├── README.md                                  # Master index, credentials & 33-demo directory
├── main.py                                    # Unified FastAPI multi-service app (SERVICE_MODE)
├── Dockerfile                                 # Production container image for Cloud Run
├── deploy_all_8_services.sh                   # One-command deployment for all 8 Cloud Run apps
├── shared/                                    # Shared Vertex AI Argon client, sandbox & UIs
├── docs/
│   ├── MASTER_HACKATHON_GUIDE.md              # Complete account dossier & keynote runbook
│   └── E2E_VERIFICATION_REPORT.json           # Automated E2E test telemetry across all 33 demos
├── tests/
│   └── e2e_verify_all_33_demos.py             # Automated E2E test runner (UI + Docs + Sandbox + Argon)
├── 00-flagship-command-portal/                # Service 0: Flagship Portal & Keynote Hub
├── 01-origination-and-sales/                  # Service 1: Squares 1.1 – 1.5
├── 02-underwriting-and-closing/               # Service 2: Squares 2.1 – 2.5
├── 03-servicing-and-mister-cooper/            # Service 3: Squares 3.1 – 3.5
├── 04-marketing-redfin-rocketmoney/           # Service 4: Squares 4.1 – 4.5
├── 05-risk-compliance-fair-lending/           # Service 5: Squares 5.1 – 5.5
├── 06-sdlc-antigravity-codemender/            # Service 6: Squares 6.1 – 6.3
└── 07-google-ce-moonshots/                    # Service 7: Squares M.1 – M.5
    └── <square-code>-<slug>/
        ├── README.md                          # Square overview & quick links
        ├── docs/REPRODUCTION_GUIDE.md         # Step-by-step blueprint & architecture diagram
        ├── code/agent.py                      # Standalone Vertex AI Gemini 4 Argon agent
        ├── code/sandbox_tool.py               # Deterministic gVisor sandbox verifier
        └── mock_data/sample_payload.json      # Realistic Rocket / Redfin / Mr. Cooper mock dataset
```
