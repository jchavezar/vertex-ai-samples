adk-drive-ae

An architecture decoupled with a Next.js front-end and a secure proxy backend delivering user credentials directly into Vertex AI Agent Engine session states.

System Sequence & Architecture

🌐
1. Next.js App
Runs locally. Requests OAuth scope for Google Drive via Identity Services popup.
🔒
2. FastAPI Backend
Accepts access token and creates the session context on Vertex Agent Engine.
🤖
3. Vertex Agent Engine
Hosts the ADK Agent, dynamically binding the credentials context.
📂
4. Drive API v3
Invoked securely directly by ADK tools with no intermediary integration layers.
Frontend UI Next.js 15 / Tailwind

Dynamic Interactive Portal

An elegant and premium browser-side portal delivering Google Identity Services integration. It triggers safe, standard user authentication popups, fetches authentication tokens, and opens interactive real-time chat sockets with the system.

  • OAuth Token Acquisition via GIS Popup
  • SSE Streaming Chat Interface
  • Dynamic UI with Interactive Feedback
Secure Proxy FastAPI / Uvicorn

Backend Orchestrator

Acts as a decoupled integration layer running locally. It intercept access tokens, makes call-to-creates sessions on Vertex AI, binds the context state securely, and maps streaming outputs back to the client.

  • Saves credentials safely in memory/sessions
  • Proxies chat streams (Server-Sent Events)
  • Maintains clean environment secrets
ADK AI Agent Google ADK / Vertex Engine

Vertex AI Agent Service

A highly specialized Google Agent Development Kit instance deployed directly onto Google Cloud's Vertex AI Agent Engine. It relies on standard system prompts and tool integrations to perform automated Google Drive searches.

  • Injected Google Drive Tools
  • OAuth Bearer Token injection on execution
  • Secure Sandbox execution in Agent Engine
